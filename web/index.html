Piczop

Keep your photos on a USB stick.
Not in the cloud.

Piczop is a Windows app you copy onto a flash drive. Plug in the drive, run Piczop.exe, click Back up now. Photos and videos are copied onto the stick. Exact copies already there are skipped. Similar photos wait for you to review — nothing is merged or deleted until you confirm.

Download installer Portable zip

Installer for a normal Windows install, or unzip the portable build for USB use.

Installer or portable

  1. Installer — run Piczop-Setup.exe for Start Menu / optional desktop shortcut.
  2. Portable — unzip Piczop-Windows.zip, run Piczop.exe (keep the whole folder).
  3. For USB: copy the app folder onto a stick and run from there (works after either download).

What you get

  • Native Windows app — no Python install for daily use
  • Library next to the exe when writable; otherwise under Local AppData
  • Originals on the PC are never deleted
  • Human-in-the-loop review for similar photos
  • No account and no cloud upload
